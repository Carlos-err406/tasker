Tasker now runs on Android and syncs tasks with your Mac through Google Drive. Both apps keep working offline, with local snapshots and optional Drive backups.

## New

- **Android app.** Controls within thumb reach, a full-screen task editor, and the full task menu with a swipe in either direction. Pull down at the top of the list to sync.
- **Sync between Mac and Android** for tasks, lists, relationships, ordering, trash and images. The most recent edit wins conflicts. Press ⌘R on the Mac to sync now.
- **All lists.** Pick "All lists" in the list picker to see every list together, each task labelled with its list (click the label to open that list). It has its own order: drag, System sort and hide completed work there like in any list. The order is saved on each device.
- **Send a task to a list from its text.** Write `>list-name` on the metadata line (for example `#book >to-download`) to create the task in, or move it to, that list. Typing `>` suggests your lists.
- **Tag completion.** Typing `#` suggests the tags you already use, most used first.
- **Backups & Sync** is now one panel. When Google's login expires, a single **Reconnect** appears and sync resumes afterwards. Uploads show their progress.

## Improved

- p3 tasks now sort below tasks without a priority.
- Tag colours use 17 hues, so different tags rarely share a colour.
- The search filter is remembered when you reopen the popup.
- Deleting a task's whole metadata line in the editor now clears it, including relationships on both tasks.
- Thin horizontal scrollbars; pasted text wraps in the editor; the code block copy button stays in its corner, and copied code no longer carries invisible characters or smart quotes.
- Slow connections no longer make Drive uploads time out.
- The Mac service keeps working after Homebrew upgrades Node.
- The Android launcher icon matches the Tasker logo.

## Install or update

**Android 11 or later:** download **tasker-android.apk** below and open it on your phone. Android may ask you to allow installation from your browser. Later updates are available under **App options → View help → About Tasker**. Existing installs update in place and keep their data.

**macOS 13.5 or later:**

```sh
curl -fsSL https://github.com/Carlos-err406/tasker/releases/latest/download/install.sh | bash
```

The installer preserves tasks, backups and Google authorization. It supplies the tested SwiftBar fork when SwiftBar is missing; that fork is ad-hoc signed and may require macOS **Open Anyway**.

Google Drive features currently require an account enrolled as a test user in Tasker's Google project, and Google asks you to reconnect about once a week while the project is in testing. Offline use does not require Google. Open **Backups & Sync** on both devices, connect the same Google account, and turn on **Sync**. A safety snapshot is created before the first merge.

Downloads include the signed Android APK, the Mac runtime archive, their SHA-256 checksum files, and the Mac installer.
