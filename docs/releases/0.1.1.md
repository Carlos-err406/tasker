Right-clicking a video, image, link, or code block now includes the full task menu alongside the content-specific actions. Edit, copy, move, change status, create subtasks, and delete without having to right-click another part of the task. Editing retains the existing focus behavior.

Releases now run automated macOS build, type, unit, WebKit, and installer checks before publication. Downloads include the runtime archive, its SHA-256 checksum, and the installer.

Install or update:

```sh
curl -fsSL https://github.com/Carlos-err406/tasker/releases/latest/download/install.sh | bash
```

Requires macOS 13.5 or later. The installer preserves tasks, backups, and Google authorization. It supplies the tested SwiftBar fork when SwiftBar is missing; that fork is ad-hoc signed and may require macOS **Open Anyway**.
