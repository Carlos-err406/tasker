Task IDs get a prefix, so agents can't mistake a short word for one, and the ID moves out of the way.

**Update the Mac and Android together.** This version changes the sync format. A device still on 1.3.0 can't read it and shows "Invalid or unsupported sync data" until it's updated. Nothing is lost while it waits.

## New

- **Prefixed task IDs.** IDs now look like `tsk_k3x9q` instead of `k3x`. Type them the same way in references (`^tsk_k3x9q`, `!`, `-^`, `-!`, `~`), or type `^` and pick a task. Agents connected through Tasker's MCP server reject anything that isn't a task ID, so a word like `lol` is never read as one.
- **Existing tasks keep recognizable IDs.** Each old ID gains the `tsk_` prefix and 2 more characters (`9kf` becomes `tsk_9kf04`), and every reference in your tasks is updated. Each device converts its own tasks the first time it opens, and both arrive at the same IDs. Searching with `id:9kf` still finds the task.
- **The ID is a chip.** It moved from under the checkbox to a `#` chip next to the task's tags, so titles get the full width. Click the chip to copy the ID.
- **Relationship lines show the linked task's menu.** "Subtask of pay the bills" no longer repeats the ID. On the Mac, right-click a relationship line for the linked task's actions (edit, copy, move, status, delete) or **Go to task**. Clicking still jumps to it.

## Changed

- Undo history is cleared once when a device converts its task IDs.

## Install or update

**Android 11 or later:** download **tasker-android.apk** below and open it on your phone. Android may ask you to allow installation from your browser. Later updates are available under **App options → View help → About Tasker**. Existing installs update in place and keep their data.

**macOS 13.5 or later:**

```sh
curl -fsSL https://github.com/Carlos-err406/tasker/releases/latest/download/install.sh | bash
```

The installer preserves tasks, backups and Google authorization. It supplies the tested SwiftBar fork when SwiftBar is missing; that fork is ad-hoc signed and may require macOS **Open Anyway**. If you use Tasker's MCP server with an AI agent, restart the agent or reconnect the server after updating.

Google Drive features currently require an account enrolled as a test user in Tasker's Google project, and Google asks you to reconnect about once a week while the project is in testing. Offline use does not require Google. Open **Backups & Sync** on both devices, connect the same Google account, and turn on **Sync**. A safety snapshot is created before the first merge.

Downloads include the signed Android APK, the Mac runtime archive, their SHA-256 checksum files, and the Mac installer.
