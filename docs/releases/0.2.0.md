Tasker now runs on Android and syncs tasks with Mac through Google Drive. Both apps keep working offline, with local snapshots and optional Drive backups.

- Choose one list at a time with the list picker; search stays within that list.
- Android puts controls within thumb reach, opens a full-screen task editor, and reveals the complete task menu with a swipe in either direction. Image actions include small previews.
- Sync combines tasks, lists, relationships, ordering, trash and managed images. The most recent recorded edit wins conflicts. Android syncs while the app is open; the Mac service syncs while running.
- Backups appear newest first, and upload controls return to idle when finished. Restoring a backup pauses sync; resuming publishes the restored changes.
- Help includes About Tasker, with the logo, credits, version and update controls. Android can download verified updates and open the system installer.

## Install or update

**Android 11 or later:** download **tasker-android.apk** below and open it on your phone. Android may ask you to allow installation from your browser. Future updates are available under **App options → View help → About Tasker**.

Tasker installs separately from Tasker Preview. Keep Preview until its changes have synced, then connect the same Google account and enable sync in Tasker. Existing production installs update in place and retain their data.

**macOS 13.5 or later:**

```sh
curl -fsSL https://github.com/Carlos-err406/tasker/releases/latest/download/install.sh | bash
```

The installer preserves tasks, backups and Google authorization. It supplies the tested SwiftBar fork when SwiftBar is missing; that fork is ad-hoc signed and may require macOS **Open Anyway**.

Google Drive features currently require an account enrolled as a test user in Tasker's Google project. Offline use does not require Google. Connect the same account on both devices under **Backups**, then choose **View sync** and enable it on each device. A safety snapshot is created before the initial merge.

Downloads include the signed Android APK, Mac runtime archive, their SHA-256 checksum files, and the Mac installer. Multiselection, background Android sync and automatic cleanup of unused Drive images remain outside this release.
