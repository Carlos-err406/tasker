# SwiftBar companion build

The optional companion is Carlos’s SwiftBar fork, built from commit `76dad9ab90587984267774ff1cf2fc116893dc06`.

- Source: https://github.com/Carlos-err406/SwiftBar/tree/76dad9ab90587984267774ff1cf2fc116893dc06
- Build: https://github.com/Carlos-err406/SwiftBar/actions/runs/36354755249
- Artifact: SwiftBar-headerless-universal.zip
- SHA-256: `8bf20f30b2eda296a24a70e8d4f0371efc5941dadae2f7ea290caac1c76344f6`

This universal macOS build contains the popover and native clipboard fixes used by Tasker. It is ad-hoc signed and not notarized. The installer does not bypass Gatekeeper or remove quarantine attributes. The license below accompanies the redistributed build.
